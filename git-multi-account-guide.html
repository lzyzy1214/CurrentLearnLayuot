一台电脑双 Git 账户配置指南

主力工作账户 + 教学实战账户 · SSH 密钥隔离 · 自动身份切换

0
总体架构

核心原理：为每个账户生成独立的 SSH 密钥对，通过 SSH config 的 Host 别名区分，Git clone 时用不同地址自动选择密钥。

账户用途SSH Host 别名密钥文件状态
账户 A（主力） 日常工作提交 github.com ~/.ssh/id_rsa 已配置
账户 B（教学） 实例教学实战 github-teach ~/.ssh/id_ed25519_teach 已配置

使用时的区别：

操作主力账户教学账户
克隆仓库 git clone git@github.com:userA/repo.git git clone git@github-teach:userB/repo.git
提交身份 全局配置自动生效 仓库内单独配置
1
生成两套 SSH 密钥
✅ 已完成 — 两套密钥已生成在 ~/.ssh/ 目录

主力账户密钥（已存在）：

# 已有的 RSA 密钥（主力工作账户）
~/.ssh/id_rsa        # 私钥
~/.ssh/id_rsa.pub     # 公钥 — 关联邮箱 3217212869@qq.com

教学账户密钥（刚生成）：

# 新生成的 ED25519 密钥（教学实战账户）
~/.ssh/id_ed25519_teach        # 私钥
~/.ssh/id_ed25519_teach.pub   # 公钥

教学账户的公钥内容（下一步需要添加到 GitHub）：

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIFr+rh3ezWJmmT3+8FiFZ4eXTWFrd8PhzdX79kpyUN8H teach-demo-account
2
配置 SSH config（区分两把密钥）
✅ 已完成 — ~/.ssh/config 文件已创建

文件内容（C:\Users\你的用户名\.ssh\config）：

# ===== SSH 多账户配置 =====

# 主力工作账户（默认，走 github.com 时自动使用）
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_rsa

# 教学实战账户（用 github-teach 别名触发）
Host github-teach
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_teach
原理说明

SSH config 的 Host 是一个"别名"。当你用 git@github.com:... 时，匹配第一个 Host github.com，使用 id_rsa。当你用 git@github-teach:... 时，匹配第二个 Host github-teach，使用 id_ed25519_teach。两个请求都连到同一个 github.com，但携带不同的 SSH 密钥。

3
将两个公钥添加到对应的 GitHub 账户
⚠️ 需要你手动操作 — 在浏览器中完成

主力账户（如果尚未添加）：

  1. 登录主力 GitHub 账户
  2. 进入 Settings → SSH and GPG keys → New SSH key
  3. Title 填 Main PC
  4. 粘贴 ~/.ssh/id_rsa.pub 的内容
  5. 点击 Add SSH key

教学账户：

  1. 退出主力账户，登录教学 GitHub 账户（可用浏览器隐私模式）
  2. 进入 Settings → SSH and GPG keys → New SSH key
  3. Title 填 Teach PC
  4. 粘贴以下内容：
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIFr+rh3ezWJmmT3+8FiFZ4eXTWFrd8PhzdX79kpyUN8H teach-demo-account

5. 点击 Add SSH key

4
验证两个账户的 SSH 认证
⚠️ 完成 Step 3 后在终端运行

测试主力账户：

ssh -T git@github.com
# 应显示：Hi 你的主力用户名! You've successfully authenticated...

测试教学账户：

ssh -T git@github-teach
# 应显示：Hi 你的教学用户名! You've successfully authenticated...
如果提示 "Are you sure you want to continue connecting?"

输入 yes 即可，这是首次连接 GitHub 的正常确认。

5
配置 Git 全局 + 仓库级身份

全局配置（主力账户，所有仓库默认使用）：

git config --global user.name "你的主力用户名"
git config --global user.email "3217212869@qq.com"

仓库级配置（教学仓库内单独覆盖）：

# 进入教学仓库目录后执行
cd /path/to/teaching-repo

git config user.name "你的教学用户名"
git config user.email "teach@example.com"

# 注意：不要加 --global，只对当前仓库生效
# 验证配置
git config user.name    # 应显示教学用户名
git config user.email   # 应显示教学邮箱
为什么要分全局和仓库级？

Git 的配置优先级：仓库级 > 全局。主力仓库不需要额外配置（继承全局），教学仓库只需在仓库内设一次仓库级配置，互不干扰。

6
克隆和使用仓库

主力仓库（正常使用，不需要任何特殊操作）：

# 直接用 github.com，自动走 id_rsa
git clone git@github.com:主力用户名/repo.git

cd repo
git config user.name    # 全局配置自动生效，不需要单独设置
# 正常 commit、push 即可

教学仓库（用 github-teach 别名）：

# 用 github-teach 替换 github.com，自动走 id_ed25519_teach
git clone git@github-teach:教学用户名/repo.git

cd repo
# 设置教学仓库的提交身份（只需设一次）
git config user.name "你的教学用户名"
git config user.email "teach@example.com"
# 正常 commit、push 即可

已有仓库切换到教学账户：

# 如果仓库之前是用 github.com 克隆的，改为 github-teach
cd /path/to/existing-repo
git remote set-url origin git@github-teach:教学用户名/repo.git

# 验证
git remote -v
# 应显示：origin  git@github-teach:教学用户名/repo.git

记忆口诀

github.com = 主力（默认行为，不用改）
github-teach = 教学（clone 和 set-url 时替换域名）
全局 = 主力身份，仓库级 = 教学身份（不带 --global）
